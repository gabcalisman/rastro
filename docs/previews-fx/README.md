# RASTRO FX / capturas reais do editor nativo

Geradas pela suíte `fx_processor` desta revisão no Linux/JUCE, com parâmetros e
componentes reais. Não são mockups, capturas do Logic ou aprovação estética do
redesign incompleto do PR #5. O FX usa desenho próprio e somente a marca RASTRO
recortada do asset existente, sem o sufixo PLAY.

independente; os controles avançados não dependem de uma aba oculta. Os workflows
nativos incluem as capturas do próprio run em `Previews/FX` no ZIP.
